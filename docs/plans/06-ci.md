# Plan 06 — CI build (GitHub Actions)

**Status:** the workflow file is committed at `.github/workflows/android.yml`. This document
explains it and lists what to do if the first runs fail.
**Sign-off needed:** none (no app permission, no schema change).

## 1. What the workflow does

Runs on every push, every pull request, and on demand. One job on `ubuntu-24.04`:

| Step | Purpose |
|---|---|
| `actions/checkout@v7` | Get the code. |
| `actions/setup-java@v6`, Temurin 21 | AGP 9.5 needs JDK 17 or newer. 21 is an LTS release. |
| `gradle/actions/setup-gradle@v6` | Gradle download and dependency cache. |
| `./gradlew testDebugUnitTest` | The unit tests (27 today), including `PrivacyManifestTest`. |
| `./gradlew assembleDebug` | Proves the APK builds. |
| Merged-manifest grep | Second privacy gate: fails if `INTERNET` or `ACCESS_NETWORK_STATE` is in the built manifest. |
| `git diff --exit-code -- app/schemas` | Fails if the build regenerated the Room schema file, which means an entity changed without a version bump. |
| Upload test reports (14 days) | HTML report, uploaded even when tests fail. |
| Upload debug APK (14 days) | Verification artifact. See §3. |

The runner image already has Android platform 37 and build-tools 36/37, so there is no
`sdkmanager` step.

## 2. Network limits

| Where | Limit | Effect |
|---|---|---|
| Claude cloud sessions (where these plans were written) | The proxy blocks `dl.google.com` / `maven.google.com`. There is no Android SDK installed. Maven Central answers but rate-limits. | **The app cannot be built or tested inside a Claude cloud session.** A faster model working there can edit code but must rely on CI for the result. |
| GitHub-hosted runners | Open internet. | Builds work. Robolectric downloads its `android-all` jar from Maven Central on the first run; the Gradle cache keeps it afterwards. |
| The app itself | No `INTERNET` permission. | Unaffected by any of this. |

Consequence for the handoff loop: **push → wait for CI → read the result** is the only test loop
available to a cloud session. `INDEX.md` builds this into the prompt template. To let cloud
sessions build locally, the owner would need to allow `dl.google.com` and `maven.google.com` in
the environment's network settings and install the Android SDK in the setup script; that is
optional.

## 3. The APK from CI must not replace the installed app

Each runner signs with a new throwaway debug key. An APK signed with a different key than the
installed app cannot update it; Android asks for an uninstall, and uninstalling deletes all notes
(`01-audit-punch-list.md` B1). The artifact is therefore named
`app-debug-apk-DO-NOT-INSTALL-OVER-EXISTING`.

**Owner decision OD-2 — pick one:**

| Option | How | Trade-off |
|---|---|---|
| A. Mac builds are the only installed builds (recommended now) | Nothing to do. CI is a check, not a delivery route. | Simple. The owner must build on the Mac to update the phone. |
| B. Shared debug keystore | Generate one keystore, store it base64 in a GitHub secret, configure `signingConfigs.debug` to use it when present, and keep a copy on the Mac. | CI APKs become installable. A secret to guard; one-time uninstall/export needed to switch keys. |
| C. Release signing | Proper release key and `minifyEnabled`. | Right long-term answer, more setup; do it before anyone else uses the app. |

## 4. Known first-run risks and their fixes

Apply a fix only if the matching failure appears. Record it in `DECISIONS.md`.

| Failure text | Cause | Fix |
|---|---|---|
| `Failed to find target android-37` | SDK folder is `android-37.0`. | In `app/build.gradle.kts`: `compileSdk { version = release(37) { minorApiLevel = 0 } }`. |
| `UnsatisfiedLinkError: no sqliteJni` in tests | `sqlite-bundled-jvm` lacks Linux natives. | Stop and report. Do not swap drivers; the test DB must stay the bundled SQLite (D3). |
| Robolectric cannot download `android-all` | Maven Central hiccup. | Re-run the job once. If it repeats, report. |
| `git diff` step fails on `app/schemas` | An entity changed without a version bump. | Not a CI problem. Follow `14-migration-test-framework.md`. |
| Setup-gradle licence or cache warning | v6 caching is a closed component. | Add `with: { cache-provider: basic }` to that step. |
| Serialization compiler/runtime mismatch error | See `03-toolchain-report.md` §2.1. | Owner decision OD-1. |
